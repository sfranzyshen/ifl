# **LLM large language model: 10 Min (Scotty)**

With every prompt sent or received it is compounded (added) to the end of the conversation and the whole conversation is then sent again … as the conversation gets bigger it fills up the context window … as the context window gets smaller the AI has less working memory (it becomes stupid, forgetful, etc) the context window fills up with tokens that are small chunks of data. Tokens are counted and used against the total usage privileges … so every token is money (cha-ching) or time (tic-toc) …

## **What is the context window (working memory)**
   The working memory for the whole conversation and it is filled up with the conversation's tokens
   

## **What are tokens (blocks of info)**
  Roughly 4 characters = 1 token (chunk) that represents the data of the conversation ... collectively these tokens represent the context window's content as well as tracked for enforcing usage limits ...
  
## **Why is it important to keep the context window clean?**
   if you ever asked your AI "why are you now so stupid?" or "why can't you do that any more?" then ...

## **Do not waste context or tokens on …**
       ● Blabber ...
       ● Insults / complaints / praise / complements
       ● Useless questions (what's the weather today?, hello?, etc)
       ● Anything that you could/should do for free in another window

## **What do you waste context and tokens on?**
       ● Documentation! (long term memory)
       ● Todo list (keep you on track)
       ● Conversation for the task at hand (/clear with every new task)

## **How to minimize context and tokens …**
       ● Sub-Agents (overall token use is the same but each agent has it's own context windows)
                    (you can have claude code recommend agents or help you setup agents up)
       ● Use Gemini-cli from claude code (gemini has very large context windows and generous free tokens use ... good for housekeeping)
       ● Todo list (don't forget steps)
       ● CLAUDE.md (if you didn't do /init when you stated … stop and do it now!)
       ● Other *.md files (other documentations file act like long term memory that you can be called up when needed)
